Вариант 4. Алгоритм выборки сотрудников
Описание:
Есть список сотрудников и количество дней, которые они работают в компании. Эти данные
представлены в виде двухмерного массива в формате текстового поля и целочисленного поля,
которое каждый день автоматически увеличивается на 1 (поле счетчика дней):

Name Number of
```
Days
Вася
Петров
N1
Иван
Иванов
N2
Петр
Третий
N3
```

Необходимо составить алгоритм выборки сотрудников из массива с юбилеями (определенное
количество отработанных дней в компании (второй столбец)), основываясь на текущей дате,
начального значения юбилея и шага выборки юбилеев. Наложить выборку на текущую (для
текущей даты) неделю (стартовый день в неделе - понедельник). Учесть, что выборка может быть
сделана в любой день недели и дату.
Начальное значение и шаг выборки – 1000 дней.
Критерии приемки:
• Результат сформировать в следующем формате: сформировать двухмерный массив, в котором
одно поле это дата дня недели, второе поле в формате «Name – ‘значение выборки’ дней»
• алгоритм в виде написанного кода на C++, Kotlin или Java. Код должен содержать main c
минимумом if
• Результаты выборки на основе исходного массива (см. ниже) для выборки в каждый день
недели

Пример:
```
Date Text

19.02
20.02 Вася Петров – 2000 дней
Коля Васечкин – 1000 дней

```
